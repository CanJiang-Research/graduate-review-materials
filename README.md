# Graduate Review Materials

Materials are grouped by subject, then by source collection. Source folders use English labels such as From_DongMeng_Collection and From_Original_Folder.

## Subjects

- Academic_Integrity: academic ethics answer key.
- Algorithms: past exams and study notes.
- Artificial_Intelligence: coursework on AI and natural dialectics.
- Computer_Networks: cheat sheet, reference table, homework reports, and routing lab files.
- Database_Systems: English database terminology.
- Graduate_Professional_Lectures: professional lecture report.
- Innovation_And_Entrepreneurship: question bank.
- Pattern_Recognition: cheat sheet, midterm exam, homework, quizzes, and code examples.
- University_And_Program_References: institutional introduction.
- Xi_Jinping_Thought: study notes.

## Source handling

Original files are unchanged. Redundant ZIP archives were not copied when their extracted contents were already present. Duplicate homework PDFs and IDE metadata were omitted.
